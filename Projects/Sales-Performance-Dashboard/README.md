# Sales Performance Dashboard

## Overview

Interactive Power BI dashboard developed using a public sales dataset from Kaggle.

## Dashboard Features

* Sales Performance Analysis
* Monthly Sales Trend
* Sales by Region
* Sales by Category
* Sales by Segment
* Top 10 Products Analysis
* Interactive Filters

## Tools Used

* Power BI
* DAX
* Data Modeling
* Data Visualization
